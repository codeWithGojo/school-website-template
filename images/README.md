# Campus photos

Drop your school’s photos here using these names so `index.html` picks them up:

| File | Suggested shot |
| --- | --- |
| `hero-campus.jpg` | Gate, courtyard, or main building (wide) |
| `office.jpg` | Head of school / office (portrait) |
| `lab.jpg` | Science lab |
| `library.jpg` | Library |
| `boarding.jpg` | Hostel / boarding house |
| `sports.jpg` | Pitch or sports hall |
| `news-science.jpg` | News card |
| `news-admissions.jpg` | News card |
| `news-founders.jpg` | News card |

Use JPEG. Keep each file under ~1 MB if you can.
